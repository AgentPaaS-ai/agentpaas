# Claim your trial

Trial access is **invite-gated**. You get a one-time claim URL from the founder (not open signup).

1. Open the claim URL in a browser you will keep using.
2. Complete account setup (password and/or Google). Use the **same email** the trial was issued for.
3. You land on the Hermes handoff card, then the dashboard.
4. Return visits: https://cloud.agentpaas.ai/login (password or Google). Login never creates a new tenant.

Do not paste API tokens into chat. CLI login uses browser approve in this same browser.
