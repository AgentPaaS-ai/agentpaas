## Root-cause findings during this pass (all fixed live)

1. **CF preset `dev` is an alias for `lite` (256MiB)** — the "dev floor" never raised the
   shape; LLM harness died at 256MiB. FIX: default preset = `basic` (1/4 vCPU, 1GiB) in
   cloud src/deployments.ts + cf_containers.ts + rebind script; allowlist the six real
   presets; reject `dev` with hint. Live app now 0.25 vCPU / 1GiB (verified via CF API).
2. **ARM harness silently embedded in amd64 image** — brew-installed daemons fell back to
   the ARM `agentpaas-harness-linux` because the release/cask ship no amd64 harness;
   CF amd64 firecracker exited 1 in 0.3s. FIX (in flight): goreleaser builds + cask installs
   `agentpaas-harness-linux-amd64`; pack gains an ELF arch guard so mismatch is a hard error,
   not silent. Live proof: repacked image f6af5292 contains x86-64 harness → invoke succeeded.
