## Key learning (user steering)

- Orchestrator must NOT lead ap-testing step-by-step. Minimal prompts only
  ("make it run in the agentpaas cloud") — the skill/plugin must drive the
  flow. Detailed prompts cheat the E2E.
- Fresh profile needs a full config.yaml (model + terminal backend + agent
  settings); a minimal config leaves the session without shell tools.
- The claim code is one-time: consuming it with curl invalidates the browser
  flow for that link. Mint fresh per test.
- Secret must be in Keychain BEFORE `cloud secrets push` — push reads local
  Keychain, it does not prompt for the value.
