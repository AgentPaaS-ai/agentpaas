# v0.3.6 release notes

**Tag:** v0.3.6 @ 00b5228  
**Audience:** brew cask customers + external T11 testers

## Install

```bash
brew tap AgentPaaS-ai/homebrew-tap
brew upgrade --cask agentpaas || brew install --cask AgentPaaS-ai/homebrew-tap/agentpaas
xattr -cr "$(brew --prefix)/bin/agentpaas" \
  "$(brew --prefix)/bin/agentpaasd" \
  "$(brew --prefix)/bin/agentpaas-harness-linux"
agentpaas version   # expect CLI: 0.3.6
```

## What's new vs 0.3.5

- `agentpaas cloud logs <run_id>`
- Invoke-token store (`~/.agentpaas/invoke-tokens.json`) — not flag/env only
