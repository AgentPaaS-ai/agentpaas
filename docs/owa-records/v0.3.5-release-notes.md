# AgentPaaS v0.3.5 Release Notes

**Date:** 2026-07-27  
**Tag:** v0.3.5  
**Base:** B1–B34 + B34.5 residual close

## Headline

v0.3.5 is a **stable point release** on the v0.3 line shipping everything proven through **B34** (runtime-native sequential pipelines) and **B34.5**, including **Hermes-absent three-stage multi-agent Docker e2e**.

It is **not** v0.4.0 (parent/child closes at B35).

## Included

- B33 MCP container services
- B34 sequential pipelines (controller, handoffs, artifacts, inspect, enable flag)
- B34.5 CancelWorkflow + MCP fence; durable start tests; pipeline register + RuntimeStageLauncher; CAS claim fix
- Multi-agent three-stage Docker e2e (`block34-multiagent-gate` ×3)
- `make ensure-docker` — Colima install/start or fail (no skip)
- BUG-036…043 fixes

## Install (Homebrew)

```bash
brew tap AgentPaaS-ai/homebrew-tap
brew install agentpaas
# upgrade:
brew update && brew upgrade agentpaas

xattr -cr "$(brew --prefix)/bin/agentpaas" \
  "$(brew --prefix)/bin/agentpaasd" \
  "$(brew --prefix)/bin/agentpaas-harness-linux"

agentpaas version   # expect 0.3.5
agentpaas doctor
```
