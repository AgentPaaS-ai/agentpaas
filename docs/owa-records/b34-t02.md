## Design decisions

**Snapshot schema_version:** `agentpaas.workflow.pipeline_snapshot/v1`

**Digest computation:**
- `WorkflowYAMLDigest`: sha256 of raw workflow bytes (caller-supplied for reproducibility)
- `SnapshotDigest`: sha256 of `json.Marshal` on snapshot struct with SnapshotDigest empty. Maps are pre-sorted with `sortedMapCopy`; Go's `json.Marshal` sorts map keys for deterministic output.
- No `time.Now`, no generated IDs, no timestamps in snapshot.

**Canonical JSON:** Go's `json.Marshal` with pre-sorted maps → deterministic per Go spec.

**PackageResolver:** Injectable interface for tests. Fake resolver in tests matches declared digests against fixture map; returns error for missing packages and returns resolved digest when mismatch is detected.

**Single source of truth:** Both pack validation and pipeline validation now enforce 2-16 stages.
