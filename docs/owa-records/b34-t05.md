## Code changes

### 1. `internal/runtime/naming.go` — Pipeline stage labels
Added 8 new label constants (LabelNodeID, LabelAttemptID, LabelPackageDigest, LabelPolicyDigest, LabelLeaseGeneration, LabelPipelineStage, LabelStageOrder) plus `PipelineStageLabels()` function that builds complete label maps with sanitization (newline/NUL rejection). All values are validated; no credential values in labels.

### 2. `internal/workflow/pipeline/launch.go` — StageLaunchJob extension
Added optional zero-value-safe container fields to `StageLaunchJob`: Image, NetworkID, PackageDigest, PolicyDigest, StageOrder, ContainerID. The existing `FakeLauncher` ignores these — no T04 test breakage.

### 3. `internal/workflow/pipeline/stage_spec.go` — BuildStageContainerSpec
- `StageLaunchRequest` struct with all container spec parameters (Image, NetworkID, binds, env, quotas)
- `BuildStageContainerSpec()` validates required fields (Image, NetworkID, RunID, NodeID, WorkflowID), enforces RW bind uniqueness (must contain nodeID/runID), validates RO binds end with ":ro", builds labels via PipelineStageLabels, returns `runtime.ContainerSpec` with exactly one NetworkID and no CapAdd.

### 4. `internal/workflow/pipeline/stage_authority.go` — StageAuthority
- `StageAuthority` struct: AllowHosts, AllowMCP, MaxActiveMs, MaxLLMSpend, NetworkEgress
- `IntersectStageAuthority()` computes intersection of workflow and stage authority: set intersection for hosts/MCP, min positive for durations, AND for egress, workflow-precedence for spend.

### 5. `internal/workflow/pipeline/stage_launcher.go` — RuntimeStageLauncher
- `RuntimeStageLauncher` wraps `runtime.RuntimeDriver` with an active container map
- `EnsureLaunch()` is idempotent: checks existing container status before creating
- `FenceStage()` stops+removes containers by workflowID+nodeID via label filter

### 6. `internal/workflow/pipeline/stage_fence.go` — AdvanceWithFence
- `AdvanceWithFence()` helper: fences previous node then calls ReconcileOnce

### 7. `internal/workflow/pipeline/stage_isolation_test.go` — 8 tests
All use a `pipelineMockDriver` (implements `runtime.RuntimeDriver`):

| TestBuildStageContainerSpec_LabelsComplete | All 11 labels present, no secret values |
| TestBuildStageContainerSpec_SingleNetwork | Exactly one NetworkID |
| TestBuildStageContainerSpec_RejectsSharedWritableBind | RW bind without nodeID/runID rejected |
| TestIntersectStageAuthority_DropsExtraHosts | Host intersection, MCP intersection, min/max rules |
| TestRuntimeStageLauncher_EnsureLaunchIdempotent | Second EnsureLaunch does not Create twice |
| TestFenceStage_StopsPriorBeforeNext | Stop+Remove called on prior, next uses different NetworkID |
| TestTwoStageSpecs_NoSharedNetworkOrRWVolume | Distinct NetworkIDs, distinct RW binds |
| TestLabelsRejectSecrets | Env preserved, labels never contain sk-/api_key values |
