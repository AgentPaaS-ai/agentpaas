## Code changes

### 1. `internal/workflow/pipeline/codes.go` — New artifact error codes
Added 6 new error codes: `ARTIFACT_DIGEST_MISMATCH`, `ARTIFACT_NOT_FOUND`, `ARTIFACT_PATH_REJECTED`, `ARTIFACT_BUDGET_EXCEEDED`, `ARTIFACT_SYMLINK_REJECTED`, `ARTIFACT_OWNER_MISMATCH`.

### 2. `internal/workflow/pipeline/artifact_store.go` — MemoryArtifactStore + ArtifactBlob
- `ArtifactStore` interface: Put, Get, VerifyDigest
- `MemoryArtifactStore`: thread-safe in-memory implementation
- Auto-computes sha256 digest on Put if not provided
- Rejects path traversal in immutable_ref
- `artifactPutToFS`: writes artifact content to filesystem with path safety

### 3. `internal/workflow/pipeline/artifact_validate.go` — Promotion + Budget + Provenance
- `WorkflowArtifactBudget`: tracks MaxTotalBytes/MaxCount with Account()
- `PromoteHandoffArtifacts`: validates against store, checks owner, digest, classification, isSafeRef, and budget
- `ValidateHandoffArtifacts`: store-agnostic validation of artifact refs
- `ProvenanceChain`: extracts producer run IDs from artifacts in order

### 4. `internal/workflow/pipeline/artifact_project.go` — RO Projection
- `ProjectPlan`: container bind list with mount root
- `ArtifactProjection`: materialized RO projection on host with Cleanup()
- `BuildROProjection`: creates temp dir, writes verified content as 0400 files, builds :ro binds
